# مطعمك عندنا — Matamak Andana Restaurant

موقع مطعم كامل (Frontend + Backend + Admin Dashboard) لمطعمك عندنا في الحسينية، الشرقية.
لا يحتاج أي تثبيت لمكتبات خارجية — يعمل بـ Node.js فقط (بدون Express).

## التشغيل

```bash
node backend/server.js
```

ثم افتح:

- الموقع: **http://localhost:8080**
- لوحة التحكم: **http://localhost:8080/admin.html**

يمكن تغيير المنفذ بمتغير البيئة `PORT`:

```bash
PORT=8080 node backend/server.js
```

## هيكل المشروع

```
al-fursan/
├── backend/
│   ├── server.js       ← الخادم + REST API (Node.js الأساسي، بدون Express)
│   ├── db.js            ← طبقة تخزين بسيطة (ملفات JSON) — يمكن استبدالها بقاعدة بيانات حقيقية لاحقًا
│   └── data/
│       ├── products.json
│       ├── categories.json
│       └── orders.json  ← يُنشأ تلقائيًا مع كل طلب جديد
└── public/               ← الموقع الأمامي (يُقدَّم كملفات ثابتة من الخادم نفسه)
    ├── index.html        ← الصفحة الرئيسية (المنيو، السلة، الطلب)
    ├── admin.html         ← لوحة تحكم صاحب المطعم
    ├── css/
    └── js/
```

## واجهة الـ API

| Method | Endpoint                    | الوصف                          |
|--------|------------------------------|---------------------------------|
| GET    | /api/products                | كل المنتجات (فلترة: `?category=` `?search=` `?featured=true`) |
| GET    | /api/products/:id            | منتج واحد                       |
| POST   | /api/products                | إضافة منتج                      |
| PUT    | /api/products/:id            | تعديل منتج                      |
| DELETE | /api/products/:id            | حذف منتج                        |
| GET    | /api/categories              | كل التصنيفات                    |
| POST   | /api/categories              | إضافة تصنيف                     |
| GET    | /api/orders                  | كل الطلبات (فلترة: `?status=`)  |
| GET    | /api/orders/:id               | طلب واحد                        |
| POST   | /api/orders                  | إنشاء طلب جديد                  |
| PATCH  | /api/orders/:id/status        | تغيير حالة الطلب                |
| DELETE | /api/orders/:id               | حذف طلب                         |
| GET    | /api/dashboard/stats          | إحصائيات اليوم للوحة التحكم     |

## المميزات المنفذة

- **موقع قابل للطلب فعليًا**: منيو، بحث، فلترة بالتصنيف، تفاصيل منتج (حجم + إضافات)، سلة، Checkout.
- **طلب عبر واتساب**: بعد تأكيد الطلب، تظهر رسالة جاهزة للإرسال مباشرة على رقم المطعم.
- **Mobile-first**: شريط سفلي ثابت، تصميم متجاوب بالكامل.
- **لوحة تحكم `/admin.html`**: نظرة عامة (طلبات/مبيعات اليوم)، إدارة الطلبات وتغيير حالتها، إدارة المنتجات (إضافة/تعديل/حذف).
- **قاعدة بيانات بسيطة (JSON files)**: سهل الفهم والتعديل، ويمكن استبدالها بـ MongoDB/PostgreSQL لاحقًا دون تغيير الـ routes (فقط `backend/db.js`).

## ملاحظات مهمة قبل النشر الفعلي

- الصور المستخدمة حاليًا صور توضيحية من الإنترنت — يُنصح باستبدالها بصور حقيقية للمطعم والوجبات.
- الأسعار والمنيو في `backend/data/products.json` تجريبية — يجب مراجعتها مع صاحب المطعم قبل النشر.
- رقم الواتساب مضبوط حاليًا على **01212315585** (بصيغة دولية `2012...` داخل `public/js/app.js`).
- عند النشر الفعلي، يُفضّل استضافة الموقع خلف HTTPS واستخدام قاعدة بيانات حقيقية بدل ملفات JSON إذا زاد عدد الطلبات.
